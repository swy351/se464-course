1. The isolated inventory desk

A five-node inventory service normally provides linearizable reservations for the last item of a product. A network partition separates two nodes in a remote shop from the other three. The application forbids promising the same item to two customers. The isolated shop can still accept local HTTP requests, but cannot communicate with the majority. Under these constraints, which behavior is the strongest defensible choice for a new reservation?

  1. Confirm locally because HTTP requests still reach the shop
  2. Confirm on both sides and call the service linearizable because each node is sequential
  3. Defer or reject confirmation on the isolated side while preserving the consistency contract
  4. Add a read cache and assume it can decide exclusive ownership

3. Denormalized names with repair

The lab rename operation updates the authoritative laboratory record immediately, then asynchronously changes embedded copies. Product requirements allow names to take five minutes to converge, but an older retry must never overwrite the new name. Design the update metadata, consumer rule and repair process.
