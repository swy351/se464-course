Read scaling and failover

A primary database can stream changes to read replicas Each replica maintains a copy of the dataset and can answer eligible reads, so many read requests no longer compete for the primary. Only if its consistency policy ensures it has the required write; otherwise use an appropriate primary or session-aware read.
