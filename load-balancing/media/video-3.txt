CDNs and anycast

The archive publishes a scanned map under an immutable versioned URL. If 2,000 eligible map requests arrive per second and edge caches serve 92 percent as fresh hits, a simplified model sends about 160 fetches per second toward origin. This estimate excludes validation and other traffic, but it shows the source of the benefit: saved content answers repeated reads near users. A private account page is a different object and cannot safely share the same reuse policy. Anycast answers a different question: which network location receives traffic for an address advertised from several sites? Routing chooses a path using network policy and topology, not a guarantee of geographic nearness. A CDN can use anycast, DNS steering and caching together. Cache directives still determine whether an answer may be reused, and route changes still need handling for established connections. A private directive excludes shared-cache storage of the whole response; a long max-age does not override it. Distinguish traffic steering, content reuse and application correctness when reviewing an edge design.


Design review and self-check

Design an archive service for the morning a newly digitized collection opens. Public scans can use versioned URLs and edge caching, while requests to reserve the last available research-room seat must reach application logic and authoritative storage. Draw DNS discovery, the edge, a regional entry point, workers and storage. Label where a read may be answered without contacting origin and where a write must be checked against current state. Now fail one worker during the surge and one region during a reservation. Explain the delay before health information changes, what happens to in-flight requests and which clients might still use cached DNS answers. A retry must not create two reservations, and a second worker must not allocate the same final seat concurrently. Those requirements need an explicit data and operation contract, not just another load balancer. A convincing design combines routing, capacity, freshness and recovery assumptions, then tests the failure cases that could violate them.
