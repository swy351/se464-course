1. Connection count hides the work

A reverse proxy selects the backend with the fewest open connections. Backend A has one HTTP/2 connection carrying 80 active requests, while backend B has ten connections carrying one active request each. All requests require similar CPU time and the machines have equal capacity. The proxy repeatedly sends new work to A. Which observation most directly explains why the policy is making a poor choice?

  1. DNS always sends clients to the wrong continent.
  2. A has less work because it has fewer connections.
  3. One connection can carry many requests, so connection count understates A’s load.
  4. B must be unhealthy because it has more connections.
